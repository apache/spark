How CI runs

Contributor builds

Push to a contributor branch → fork's Build workflow → tests selected from changed files → results reported on the pull request.

Upstream builds

Sampled upstream pushes → Build workflow → full test matrix. Scheduled variants provide regular coverage of extra configurations.

Branch coverage

Schedules on master → master builds or maintenance-branch dispatches → branch builds. Unchanged maintenance branches can skip a dispatch.
